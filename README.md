# Dress Ecommerce Starter

Static fashion ecommerce homepage inspired by a multi-category clothing storefront.

## Structure

- `client` - React frontend for the static homepage
- `server` - Node.js + Express + PostgreSQL starter backend

## Frontend

```bash
cd client
npm install
npm run dev
```

## Backend

```bash
cd server
npm install
npm run dev
```
